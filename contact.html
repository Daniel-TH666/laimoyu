联系方式

本站没有客服团队，也没有在线表单后台。所有沟通都走下面这两条公开渠道，站长会定期查看并处理。

📮推荐一个网站

最快的办法是直接用首页的推荐表单：填好名称、网址、分类和一句话简介，点提交， 页面会自动带着填好的内容跳到 GitHub 新建 Issue 页面，你只要点一下绿色的 Submit new issue 就完成了。

去首页填写推荐表 →

🐙GitHub Issues（通用渠道）

本站的代码和站点数据都托管在公开的 GitHub 仓库里，所有反馈都可以通过 Issues 提交。 需要 GitHub 账号，但不需要你懂技术，像发帖一样把问题写清楚就行。

打开 Issues 页面 ↗

提示：Issue 内容是公开可见的，请不要在里面填写手机号、邮箱等个人信息。

🗂️各类请求怎么提

① 链接失效 / 站点变质

在标题里写上「失效：站点名」，正文附上原来的网址，如果能说一下打开时看到什么（打不开、跳转到别的站、变成赌博页）就更好，我们会核实后下架或替换。

② 点评写错了 / 与实际不符

请指明是哪一条、哪里不对。点评都是人工写的，出现偏差很正常，确认后会直接改。

③ 网站推荐

请附上名称、网址、建议分类，以及一句话说明为什么值得收录。自荐也可以，但同样要过人工审核，不保证一定收录。

④ 友情链接

请在 Issues 里说明你的站点名称、网址、内容方向，并确认你的站上已经放了本站链接。要求：内容合法合规、能正常访问、不涉黄赌毒与盗版。我们会先实际打开确认再加。

⑤ 广告与商务合作

本站页面上预留了若干广告位，目前均为留空状态，尚未开始招商。 后续如果开放，会在这里同步说明形式与联系方式，并依法对广告内容做显著标注。 请不要通过 Issues 发送需要付费的推广，这类内容不会被采纳。

⑥ 权利人下架请求

如果你是某个被收录站点的权利人，不希望本站链接到你的网站，请在 Issues 中提交下架请求， 并附上：具体链接、权利证明（如域名归属或在站内发布的公告）、以及你的联系方式。 核实后我们会尽快移除，不需要走复杂流程。

⑦ 安全与隐私问题

如果你在本站发现了安全漏洞（例如某处可以注入脚本），请通过 Issues 告知，我们会尽快修复； 涉及敏感细节的话，可以只描述位置，不用公开利用方法。

✉️电子邮件

本站目前不公开站长邮箱，以避免被批量抓取用于发送垃圾邮件。 上述所有事项都可以通过 GitHub Issues 处理；如果你的情况确实不便公开提交， 可以在 Issues 里留言说明，我们会安排其他方式与你联系。
