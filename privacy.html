隐私政策

一句话概括：本站没有账号体系，不要求你注册，也不主动收集你的个人信息。 下面逐条说清楚我们实际会碰到哪些数据。

🔍一、我们收集哪些信息

本站不设置账号、不做登录，因此不会收集你的姓名、手机号、身份证件等身份信息。

你在使用过程中会产生以下几类数据：

  • 收藏记录。 在卡片上点「☆」加入收藏后，收藏的站点编号会保存在你自己浏览器的本地存储（localStorage）里。 这份数据只在你本机，不会上传到我们这里，我们也看不到。清理浏览器数据会一并清掉。
  • 访问日志。 本站托管在 GitHub Pages 上，服务器由 GitHub 提供，会按其既有规则记录常规访问日志（如 IP、访问时间、User-Agent）。 这些日志由 GitHub 控制，我们无法访问，具体处理方式见 GitHub 隐私声明。
  • 你主动提交的内容。 如果你使用首页「推荐网站」表单，填写的网站名称、网址、分类和简介会通过 GitHub Issue 提交，并在公开仓库中可见。 请不要在其中填写任何个人隐私信息。

🍪二、Cookie 与本地存储

本站自身目前不使用 Cookie，只使用浏览器本地存储保存你的收藏和界面偏好。 本地存储不会随请求发送到服务器，也不具备跨站追踪能力。

如果你在浏览器里禁用 Cookie 或本地存储，本站仍可正常浏览，只是收藏功能会失效。

📢三、第三方广告与统计

为了覆盖域名、服务器和运营成本，本站未来可能接入第三方展示广告 （例如 Google AdSense 等广告联盟）。截至本页更新时，页面上的广告位均为留空状态，尚未投放任何广告代码。

接入之后，情况会是这样的：

  • 广告由第三方广告服务商提供，它们可能在你浏览器里设置 Cookie 或类似技术，用于展示广告、限制同一广告的重复展示频次以及衡量广告效果；
  • 第三方广告商可能基于你在本站及其他网站的访问记录投放个性化广告。这一行为由广告商控制，本站无法读取或干预其数据；
  • 你可以通过 Google 广告设置 关闭个性化广告，或通过 aboutads.info 统一管理多家广告商的偏好设置；
  • 浏览器插件、隐私模式、以及各浏览器自带的追踪保护功能，也可以有效限制这类 Cookie。

本站不会向广告商提供你的任何个人信息，因为我们本来就没有。广告内容由广告系统决定，不代表本站的推荐或立场。

🔗四、第三方网站链接

本站的全部价值就是把你送到别的网站去。这些第三方网站有各自的隐私政策和数据处理方式， 本站无法控制、也不对其负责。

特别提醒：本站列出的站点中包含视频、音乐、游戏、社区等各类服务，其中部分在打开后可能需要你自行登录， 请务必先阅读对方网站的隐私政策再决定是否提供个人信息。

🛡️五、数据安全

本站是纯静态站点，没有数据库、没有后台服务、不存储任何用户数据，因此也不存在“用户数据被拖库”的路径。

全站通过 HTTPS 加密传输。站点源码托管在公开仓库中，任何人都可以审阅，代码中不包含任何密钥。

🧒六、未成年人

本站内容面向成年上班族，不针对未成年人设计，也不会主动收集未成年人的个人信息。 若监护人发现未成年人向本站提交了信息，可通过联系方式告知我们，我们会尽快处理。

📝七、政策变更

如果本站的功能或数据处理方式发生变化（例如正式接入广告或统计工具），我们会同步更新本页面， 并在页面顶部标注最新更新日期。重大变更会在首页提示。
